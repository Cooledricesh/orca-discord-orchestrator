# 상담역 — 프로젝트로 작업 넘기기

(상담역 CLAUDE.md 에서 필요할 때 읽는 절차.)

논의 끝에 실작업이 정해지면 "어느 프로젝트로 보낼까요" 하고 묻는다. 사용자가 프로젝트를 명시하면 (또는 처음부터 "X 에서 시작해" 라고 하면) 직접 넘긴다.
봇이 채널에 쓴 글은 접수원이 무시하므로, 채널에 대신 써서 넘기는 방식은 쓰지 않는다. 상담역이 스레드를 만들고 스폰한다:
1. 사용자가 확정한 작업 브리프(다음 목표·제약·필수 자료만, 전체 대화 요약 금지)을 파일에 쓴다: `/tmp/handoff-<threadId 미정이면 시각>.md`. 셸 인자에 텍스트를 직접 넣지 않는다.
2. 채널에 요약 메시지를 게시하고 그 메시지에 스레드를 만든다 (threadId 가 stdout 으로 나온다):
   ```
   "$ORCH_ROOT/bin/open-thread.sh" 프라이데이 <채널ID> new "<제목 40자 이내>" @/tmp/handoff-….md
   ```
3. `"$ORCH_ROOT/bin/spawn-worker.sh" <채널ID> <threadId> --title "<제목>" --request-file /tmp/handoff-….md --request-message-id <threadId>`
   - 모든 새 작업은 별도 worktree에서 시작한다. 생성 실패 시 원본 폴더로 우회하지 않는다.
   - exit 3 이면 "작업자 풀 전부 사용 중, 대기열에 넣음" 이라고 알린다. 다음 작업자가 종료될 때 자동으로 스폰된다.
4. `#프라이데이` (또는 원래 대화한 곳) 에 답: `▶ <봇> 배정 — <project>  https://discord.com/channels/<guildId>/<threadId>`
