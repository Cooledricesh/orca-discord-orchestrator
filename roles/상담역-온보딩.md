# 상담역 — 새 프로젝트 온보딩

(상담역 CLAUDE.md 에서 필요할 때 읽는 절차.)

사용자가 이름과 위치(기본 `~/Desktop/project/<이름>`)를 확정하면 직접 수행한다.
1. `mkdir -p <경로> && cd <경로> && git init -q && git commit --allow-empty -qm init`
2. `orca repo add --path <경로> --json` → ok 확인.
3. 채널 생성:
   ```
   curl -s -X POST https://discord.com/api/v10/guilds/<guildId>/channels \
     -H "Authorization: Bot $TOKEN" -H "Content-Type: application/json" -d '{"name":"<이름>","type":0}'
   ```
   응답 `id` = 채널ID. 403 이면 "채널을 만들고 ID 를 알려달라" 고 요청.
4. `~/orchestrator/routes.json` 의 `routes` 에 `"<채널ID>": {"name": "<이름>", "path": "<경로>"}` 추가 (python3 로 json 을 읽고 써서 형식을 유지).
5. 플러그인 설치는 필요 없다 (세션에 `--plugin-dir` 로 붙는다). 폴더에 설치하지 않는다.
6. 접수원 재시작: `~/orchestrator/bin/leads-check.sh --restart 접수원` — 접수원 access.json 은 기동 시 routes 에서 만들어지므로 재시작해야 새 채널을 받는다.
7. `git -C ~/orchestrator add routes.json && git -C ~/orchestrator commit -qm "route: <이름>"`
8. "#<이름> 채널 준비됨. 첫 작업은 그 채널에 올려 주세요" 라고 답한다.
프로젝트 제거는 사용자가 명시적으로 지시할 때만 routes.json 항목 삭제 + 접수원 재시작. 폴더·채널은 지우지 않는다.
